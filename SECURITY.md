# Security / 安全

Report sensitive vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ascube/ReviewForge/security/advisories/new). Do not put exploit details, credentials or private repository content in a public issue. If private reporting is unavailable, open an issue asking the maintainer to enable it, without disclosing the vulnerability.

The latest published release is the maintenance target. This is a personal project and no response-time or security-support SLA is promised.

ReviewForge stores drafts locally, encrypts credentials using the operating system, and sends selected context to Copilot when AI work is requested. Explicit approvals guard applying code, pushing, posting and resolving. Review generated content yourself; AI output is not a security certification. See the user guide for distribution/signing limitations.

安全问题请通过 GitHub 私密漏洞报告提交；不要在公开 Issue 暴露漏洞细节、凭据或私有仓库内容。若入口不可用，仅请求维护者开启，不附敏感内容。目前维护目标是最新发布版，个人项目不承诺响应时限。请自行审核 AI 结果，AI 审查不等同于安全认证。
